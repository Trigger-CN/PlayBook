我把个人网站做成了一台可玩的记录机

从按钮触感开始，为长期内容建立一组会说话的视觉规则：深度来自按钮面与底座的组合，反馈来自明确但不聒噪的位移。

大多数个人网站的问题不是内容不够，而是界面没有性格。我想要的是一个每次打开都想按一按的地方——于是有了这套「玩具盒」视觉系统。

为什么从按钮开始

实体按键的魅力在于：按下之前你就知道它会被按下。数字界面缺少这种预期，所以我用两层结构模拟它——明亮的按钮面（cap）和深色的实体底座（base）。

深度不是阴影的堆叠，而是结构的诚实表达。

六色角色与底座

每种交互色都定义一对 token：按钮面负责亲和力，底座负责重量。日间与夜间主题各自维护一整套变量，切换时无需改动任何组件代码。

tokens.css
:root {
  --coral: #ff656c;      /* 按钮 cap */
  --coral-base: #72002f; /* 实体底座 */
}
[data-theme="night"] {
  --coral: #ff7379;
  --coral-base: #5a082e;
}

一次按压的解剖

按压反馈只需要三个状态，全部通过 transform 完成，不触碰布局属性：

  • 静止：面上浮 8px，露出底座；
  • hover：上浮至 11px，轻微提亮；
  • active：落回 2px，几乎贴合底座。

动效时长控制在 80–150ms，快到不拖泥带水，慢到可以被感知。

克制的代价与回报

阅读区被刻意排除在按压体系之外：正文、引用和表格保持平面。操作区域才强调反馈——这让每次「按下」都有了明确含义。更多背景可参考其他设计系统文章。

玩具盒的最终目标不是好玩本身，而是让长期记录这件事值得期待。
