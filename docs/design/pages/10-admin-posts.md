# 后台文章管理设计

## 1. 页面目标

提供文章查找、状态管理、预览和发布工作流。MVP 文章为 MDX 文件时先提供只读索引和构建信息；在线书写与编辑见 [文章书写页](15-post-editor.md)。

- 路由：`/admin/posts`、`/admin/posts/new`、`/admin/posts/[id]`
- 阶段：列表为只读索引 Phase 8；在线书写/编辑见 [文章书写页](15-post-editor.md)
- 对应需求：`REQ-ADMIN-006/007`

## 2. 页面布局设计

### 2.1 文章列表

- 顶部：标题、搜索、状态/分类筛选、新建按钮（能力启用后）。
- 主体：紧凑表格，列为标题、状态、发布时间、更新时间、分类、浏览量、操作。
- 批量栏：仅在选择后出现，MVP 可不提供批量发布/删除。
- 分页位于表格下方。

### 2.2 书写与编辑页

书写/编辑页拥有独立的三栏工作区与发布流程，详细布局见 [文章书写页](15-post-editor.md)。本文档只负责列表页与各入口。

## 3. 功能设计

### 3.1 列表

- 搜索标题/slug；筛选 draft/published/archived。
- 排序更新时间/发布时间。
- 操作：编辑、预览、复制公开链接、归档；删除需二次确认。
- 文件型 MDX 模式下显示来源 `file`，编辑动作指向本地流程说明或隐藏。

### 3.2 书写、预览与发布

书写、预览、发布前校验、并发与版本控制由 [文章书写页](15-post-editor.md) 统一定义，避免两处描述冲突。

## 4. 页面状态

- 列表 loading/empty/error。
- 删除/归档成功后从列表移除并提示可恢复策略。
- 编辑器与发布相关状态见 [文章书写页](15-post-editor.md)。

## 5. 数据与权限

MVP 读取构建期文章索引；后续 `posts` 表扩展正文来源、状态和版本字段。只有管理员可创建/更新/删除。媒体上传依赖媒体模块。

## 6. 实现技术要点

- 列表为受保护 Server Component；筛选写入 query。
- 表单使用 React Hook Form + Zod，Server Action 再校验。
- MDX 预览在隔离服务端编译，组件白名单与公开文章一致。
- 在线编辑启用前定义 repository interface，使文件源和数据库源共享读取契约。
- 发布事务至少协调文章写入、活动事件和缓存失效；外部构建失败需记录状态。
- 删除默认采用 archive/soft delete，永久删除作为独立高风险动作。

## 7. 可访问性与安全

- 表格有 caption/列标题，行操作菜单可键盘操作。
- 编辑器有独立 label；Markdown 预览不是唯一编辑方式。
- 确认对话框说明文章名称和后果，初始焦点放在取消。
- 草稿预览 `noindex`，token 不写入日志或公开 referrer。
- 上传、正文和自定义组件都做服务端验证。

## 8. 验收标准

- 列表搜索、筛选、排序和分页可恢复。
- 文件型与数据库型文章来源明确。
- 发布前校验覆盖 frontmatter、MDX、图片和 slug。
- 保存/发布失败不丢失正文；并发编辑不静默覆盖。
- 发布后首页、列表、详情、sitemap/RSS 正确失效。
