# 时间轴列表页设计

## 1. 页面目标

时间轴列表页按时间组织个人事件、想法、项目进展和里程碑，让访客快速浏览长期轨迹并进入节点详情。对应 `REQ-TL-001` 至 `REQ-TL-010`。

- 路由：`/timeline`
- 阶段：MVP
- 主要任务：按年月浏览、按类型筛选、查看含图节点、进入详情

## 2. 页面布局设计

### 2.1 桌面端

1. Header 和页面标题区。
2. 摘要：节点总数、时间跨度、最近更新时间。
3. 筛选区：年份、类型和可选关键字。
4. 时间轴主体：左侧年份/月导航，右侧纵向连接线和节点卡片。
5. 分页或按年份加载入口。
6. Footer。

时间连接线用于表达顺序，不作为唯一信息来源。节点卡使用不同按钮面/底座色对区分类型，但必须同时显示类型文本。

### 2.2 移动端

- 年份导航改为横向滚动的选项组或下拉菜单。
- 连接线贴近左侧，节点卡占剩余宽度。
- 图片位于卡片顶部，文本完整换行。
- 筛选 chip 自动换行，保留立体底座。

## 3. 功能设计

### 3.1 分组与排序

- 以 `occurred_at` 倒序排列，不使用 `created_at` 代替事件发生时间。
- 先按年份，再按月份分组；分组标题使用语义标题和可链接锚点。
- 同一时间节点按稳定次序排序，避免分页后跳动。

### 3.2 节点类型

至少支持：`note`、`milestone`、`project`、`travel`、`reading`、`release`。每种类型定义标签、色对和图标；未知类型使用中性 fallback，不能导致页面崩溃。

### 3.3 筛选与 URL

```text
/timeline?year=2026&type=project&page=2
```

- 年份、类型写入 query，支持刷新和分享。
- 切换筛选重置分页。
- 无匹配结果显示当前条件和清除按钮。
- MVP 可不做全文搜索。

### 3.4 节点卡片

显示发生时间、类型、标题、内容摘要、可选缩略图、外链标记、点赞/评论计数。整卡主链接指向 `/timeline/[id]`，外部链接放在详情页或作为清晰的次操作，避免嵌套链接。

### 3.5 分页

优先按年份或游标分页，避免高 offset。首屏返回最近一段内容，底部“查看更早记录”加载下一游标；URL 应能表达可恢复的位置。

## 4. 页面状态

- **Loading**：服务端首屏直接渲染；增量加载使用与节点同高的占位。
- **Empty site**：展示时间轴用途说明和返回首页入口。
- **Filtered empty**：保留筛选器并提供清除条件。
- **Load more failure**：已加载节点保留，底部显示重试。
- **Missing image**：使用类型占位图，不收缩卡片。

## 5. 数据与依赖

核心数据来自 `timeline_items`：

```ts
type TimelineItem = {
  id: string;
  title?: string;
  content: string;
  type: TimelineType;
  imageUrl?: string;
  externalUrl?: string;
  occurredAt: string;
  createdAt: string;
  updatedAt?: string;
};
```

列表额外批量读取点赞/评论聚合计数，禁止每个节点单独查询。依赖时间轴领域、媒体、点赞、评论、数据缓存模块。

## 6. 实现技术要点

- `app/(site)/timeline/page.tsx` 使用 Server Component。
- Supabase 查询明确字段、类型和时间范围，按 `occurred_at desc, id desc` 排序。
- 公开查询只返回已发布节点；如增加状态字段，RLS 同步限制。
- 服务端把扁平结果转换为 `year -> month -> items`，客户端只负责轻量筛选交互或加载更多。
- 推荐 ISR 1 至 5 分钟；节点发布/修改后 `revalidateTag('timeline')` 和 `revalidateTag('home')`。
- 过滤 query 通过白名单解析；非法年份/类型回退或展示无结果，不直接拼接 SQL。

## 7. 可访问性与响应式

- 连接线和圆点为装饰，`aria-hidden="true"`。
- 日期使用 `<time datetime>`；分组层级不跳级。
- 类型不能仅用颜色表达。
- 加载更多后不强制抢焦点，可用 `aria-live` 宣布新增数量。
- 390px 检查图片、标题、外链文本和筛选器无溢出。

## 8. 验收标准

- 节点按发生时间正确排序并按年月分组。
- 六种基础类型有文本、图标和颜色区分。
- 筛选条件可通过 URL 恢复，空结果可清除。
- 带图节点显示缩略图，缺图有稳定占位。
- 节点卡可进入详情，互动计数批量获取。
- 桌面和移动布局可读、可操作且无横向页面滚动。
