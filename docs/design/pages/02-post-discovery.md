# 文章发现页设计

## 1. 页面目标

文章发现页统一承载文章总列表、标签页和分类页，让读者通过浏览、筛选和可分享 URL 找到内容。对应 `REQ-ART-001`、`REQ-ART-003`、`REQ-CONT-002`、`REQ-SEO-003`。

- 路由：`/posts`、`/tags/[tag]`、`/categories/[category]`
- 可选增强：`/tags`、`/categories`
- 阶段：文章列表、标签/分类为 MVP；全文搜索为增强

## 2. 页面布局设计

### 2.1 桌面端

1. Header 与面包屑。
2. 页面标题、结果摘要和简短说明。
3. 筛选工具栏：搜索输入、标签/分类 chip、排序菜单；工具栏不是浮动卡片。
4. 主内容双栏：左侧文章列表，右侧为标签、分类和精选文章辅助区。
5. 分页或“加载更多”。
6. Footer。

文章列表使用可按压文本卡片，每张卡展示缩略图、标题、摘要、发布时间、阅读时间、标签和分类。单卡只能有一个主链接；标签链接需通过结构规避嵌套交互元素。

### 2.2 移动端

- 筛选工具栏纵向排列，标签 chip 可换行。
- 辅助栏移到列表之后，或折叠为筛选抽屉。
- 卡片缩略图位于上方，文本在下方。
- 分页按钮保持足够触控面积，不使用只有数字的密集小控件。

## 3. 功能设计

### 3.1 列表与排序

默认只展示 `draft: false` 且 `publishedAt <= now` 的文章，按发布时间倒序。支持：

- 最新发布（默认）。
- 最近更新。
- 精选优先。
- 热门排序为后续能力，数据来自聚合浏览/点赞指标。

### 3.2 标签和分类

- 标签为多值、较细粒度；分类为单值、较稳定。
- 标签/分类 slug 必须规范化并进行 URI 编码。
- 访问不存在的标签或分类时返回有意义的空状态，不伪造 500。
- 筛选状态写入路径或 query，刷新、分享和前进后退均可恢复。

推荐 query：

```text
/posts?q=design&tag=web&category=build&sort=published&page=2
```

专用路径 `/tags/[tag]` 和 `/categories/[category]` 可复用同一查询与列表组件。

### 3.3 搜索

MVP 可只搜索构建期文章索引中的标题、摘要和标签；正文全文搜索后续实现。搜索输入需防抖，但 URL 更新和结果提交要可预测。没有 JavaScript 时仍可通过 GET 表单提交查询。

### 3.4 分页

- 推荐服务端分页，每页 10 至 20 篇。
- 页码超过范围时规范化到有效页或返回 404，避免重复 SEO 页面。
- 切换筛选条件时页码重置为 1。

## 4. 页面状态

- **初始加载**：服务端直接输出结果，不依赖客户端请求后闪现。
- **筛选中**：保留工具栏尺寸，可用导航 pending 状态提示。
- **无结果**：显示当前筛选条件和“清除筛选”立体按钮。
- **无文章**：面向站点初期的友好空状态，与搜索无结果区分。
- **参数错误**：忽略未知参数；非法排序回退到默认值。

## 5. 数据与 URL 契约

文章索引对象至少包含：

```ts
type PostIndexItem = {
  slug: string;
  title: string;
  summary: string;
  publishedAt: string;
  updatedAt?: string;
  tags: string[];
  category?: string;
  cover?: string;
  coverAlt?: string;
  featured?: boolean;
  readingTime: number;
};
```

数据来自构建期扫描的 MDX 索引；热门指标可在服务端批量合并，禁止逐卡请求数据库。

## 6. 实现技术要点

- `/posts/page.tsx`、`/tags/[tag]/page.tsx`、`/categories/[category]/page.tsx` 共享 `PostDiscoveryPage` 编排组件。
- query 使用 Zod 或显式解析器校验，排序字段使用白名单。
- 构建期生成文章索引，避免每次请求解析全部 MDX。
- 列表页使用 SSG/ISR；搜索 query 页面可以动态渲染或基于轻量索引服务端过滤。
- 标签和分类路径通过 `generateStaticParams` 生成已知页面。
- 每个筛选结果设置 canonical；复杂组合搜索页通常 `noindex,follow`，专用标签/分类页可索引。
- 卡片缩略图采用固定 `aspect-ratio`，防止图片加载导致布局位移。

## 7. 可访问性与响应式

- 搜索框有可见 label；清除搜索是按钮，不仅依赖输入框内图标。
- 当前标签使用 `aria-current` 或 `aria-pressed`，但选中状态不模拟持续物理按下。
- 结果更新后焦点不被强制跳走；必要时用礼貌级 `aria-live` 宣布结果数。
- 卡片标题链接拥有明确名称，缩略图 alt 来自 frontmatter。

## 8. 验收标准

- 列表展示需求规定的标题、摘要、时间、标签、分类和缩略图。
- 标签、分类、搜索、排序和分页可通过 URL 恢复。
- 草稿和未来文章不会公开。
- 无结果、非法参数和图片缺失有明确状态。
- 标签/分类页面 metadata、canonical 和索引策略正确。
- 390px 下筛选控件和卡片无横向溢出。
