# 文章详情页设计

## 1. 页面目标

文章详情页提供稳定、舒适、可分享的长文阅读体验，并承载目录、代码、图片、浏览量、点赞和评论。对应 `REQ-ART-002` 至 `REQ-ART-011`、`REQ-SEO-001` 至 `REQ-SEO-007`。

- 路由：`/posts/[slug]`
- 阶段：MVP
- 主要任务：阅读正文、定位章节、查看媒体、点赞、评论、继续阅读

## 2. 页面布局设计

### 2.1 桌面端

1. Header 和文章面包屑。
2. 文章头部：分类、标题、摘要、发布时间/更新时间、阅读时间、标签。
3. 封面图：保持真实内容可检查，不做过暗蒙层。
4. 阅读区三栏逻辑：左侧分享/返回操作，中间正文，右侧粘性目录；实际可压缩为正文 + 目录两栏。
5. 文末信息：更新时间、标签、上一篇/下一篇或相关文章。
6. 互动区：浏览量、点赞按钮、评论列表和评论表单。
7. Footer。

正文推荐宽度 `680px - 760px`。目录、分享栏不应挤压正文到不可读宽度。代码块、表格和大图可以突破正文宽度，但必须受页面容器限制。

### 2.2 移动端

- 目录折叠为“本文目录”按钮和可关闭面板，或置于正文前。
- 标题使用页面级字号，不随视口连续缩放。
- 代码块允许容器内横向滚动，页面本身不横向滚动。
- 点赞和评论操作靠近文末，使用完整立体小按钮。
- 图片可全宽，caption 保持可读。

## 3. 功能设计

### 3.1 MDX 阅读

支持标题、段落、链接、图片、列表、引用、表格、代码块及白名单自定义组件。自动为标题生成稳定 ID，目录只收集 `h2/h3`。

- 外链标识并安全打开。
- 代码块支持语言标记、行高亮和复制按钮。
- 表格在窄屏放入可滚动容器。
- 自定义组件不得在构建期执行不可信代码。

### 3.2 文章元信息

- `publishedAt` 必须展示。
- `updatedAt` 与发布时间差异明显时展示“更新于”。
- 阅读时间构建期计算。
- 标签和分类链接到发现页。
- 草稿仅管理员预览可访问，公开路由返回 404。

### 3.3 目录

- 构建期从 AST 生成，避免客户端扫描 DOM。
- 当前章节高亮可用小型 Client Component + IntersectionObserver。
- 点击目录使用原生锚点；`scroll-margin-top` 避免标题被固定 Header 遮挡。

### 3.4 互动

- 页面稳定呈现后异步记录浏览量，不阻塞正文。
- 点赞使用乐观更新，失败回滚并给出可读错误。
- 评论只展示 `approved`；匿名提交默认进入 `pending`。
- 提交成功提示“审核后显示”，不立即伪装成公开评论。

### 3.5 相关文章

按共同标签/分类计算 2 至 4 篇，排除当前文章。无匹配时可以展示最近文章，不做逐请求昂贵推荐。

## 4. 页面状态

- **Not found**：slug 不存在、草稿或未来文章统一走 404，避免泄漏状态。
- **正文错误**：构建期阻止发布；运行时异常展示错误边界和返回文章列表。
- **互动 loading**：正文先呈现，计数使用稳定占位。
- **评论 empty**：显示“还没有公开评论”和评论入口。
- **评论提交中/成功/失败**：按钮锁定并保持宽度，错误关联到表单字段。
- **图片失败**：保留 alt/caption 和稳定占位。

## 5. 数据与依赖

文章 frontmatter 遵循内容管线定义；互动统一使用：

```text
target_type = post
target_id = posts.id 或稳定 slug 映射
```

公开渲染需要：MDX 正文、TOC、文章索引项、互动聚合计数、已审核评论。依赖内容管线、评论、点赞、浏览量、媒体资源、SEO 分享模块。

## 6. 实现技术要点

- `app/(site)/posts/[slug]/page.tsx` 使用 `generateStaticParams` 和静态生成。
- `generateMetadata` 从 frontmatter 生成 title、description、canonical、OG、Article JSON-LD。
- MDX 使用 remark/rehype 处理 slug、目录、代码高亮和图片元数据。
- 评论、点赞、浏览记录分别为小型客户端岛，不将正文转为 Client Component。
- 浏览量 Route Handler 接收 path、target type/id；服务端校验并去重。
- 评论表单使用 React Hook Form + Zod；服务端再次校验。
- 文章内容变更后重新验证文章路径、文章列表、首页和 sitemap tag。

## 7. 性能、可访问性与安全

- 正文 HTML 构建期生成，代码高亮不在客户端运行。
- 封面及正文图片提供尺寸、`sizes` 和延迟加载；首张 LCP 图可优先。
- 正文颜色在两套主题下满足对比度；链接不能只用颜色区分。
- 目录可键盘操作，复制代码按钮有状态提示。
- 评论只允许纯文本/有限换行并进行输出转义，防止 XSS。
- 不在客户端暴露未审核评论或管理员字段。

## 8. 验收标准

- 所有 MDX 基础元素、自定义组件、代码高亮和目录正确渲染。
- 页面展示完整元信息、浏览量、点赞和评论区。
- 草稿不公开；不存在 slug 返回 404。
- metadata、canonical、OG 和结构化数据正确。
- 评论提交进入待审核，错误和成功状态明确。
- 390px 下正文、代码、表格、目录和操作按钮无页面级溢出。
